# @studio/study-iq-scene

The graphic scene for 《学习与智商》: twelve marks, a board of chess pieces, the same pieces read
as four groups, and two ways to study. Drawn entirely from the requested frame.

## Use

```svml
<import as="study" from="@studio/study-iq-scene@1"/>

<study:Scene id="film-scene" timeline={program.timeline} within={canvas.bounds} font={font}
  during={program.window} title="学习与智商" tag="NO.01 · 组块"/>
```

| Attribute | Meaning |
| --- | --- |
| `timeline` | The absolute Timeline the scene is placed on. |
| `within` | The picture-plane Frame the scene fills. |
| `font` | The FontStack for every word on screen. |
| `during` | The scene's lifetime. Outside it nothing is drawn. |
| `title` | Top-left identity line. |
| `tag` | Top-right tag line. |

One output: `visual`. No children, no assets, no model calls.

## What it draws

| Local seconds | Picture |
| --- | --- |
| 0 - 13 | Twelve marks arrive one accent at a time, then leave. |
| 12 - 30 | A capacity bar fills to seven and the rest spills upward. |
| 30 - 52 | An 8x8 board draws in and twelve pieces take their squares. |
| 52 - 70 | The pieces jolt to a random arrangement; the board recedes and two bars show the advantage collapsing. |
| 70 - 104 | Three pieces at a time are boxed as one group, then each group merges into a single disc. |
| 104 - 134 | Two rings: repetition that fades against retrieval that deepens. |
| 134 - 146 | Everything collapses to a line; the accent rings continue. |

## How it is built

`src/content.ts` holds every word and when it is said, plus the two board arrangements and the
grouping. `src/beats.ts` is generated by `tools/beat_grid.py` from the analysed soundtrack, so the
accent pulse is measured rather than assumed. `src/render.ts` computes one frame from the requested
frame alone: the canvas draws the picture, the DOM text elements carry the words, and both are
driven by the same local frame number, which keeps seeking and parallel rendering deterministic.

The single-component boundary is right for this piece: the marks, the board, the groups and the
rings share one palette, one beat pulse and one layout, and they hand off to each other without a
cut. There is nothing here a second author would want to control.

## Notes for the next edit

- Visual IR style values need CSS units. `top: 132` is dropped silently; `top: "132px"` works.
- Exact fonts forbid `font-weight` in the element style. Weight comes from the wrapper's CSS, which
  the text inherits.
- Element opacity must be set on the element the `setup` function can reach, not on the styled child.
