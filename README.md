# 接单的四个层级
为了让你更清晰地理解，我将接单分为四个层级，看看你现在处于哪一层，又想往哪一层走：

层级一：劳动力型（搬砖）
典型任务：大学生毕设、简单的 HTML 静态页面、数据录入脚本。
特点：门槛极低，价格透明，甚至可以说是“内卷”。
我的点评：这是新手村，可以赚点饭钱，但不要沉溺于此，因为它无法提升你的核心竞争力。
层级二：技能型（工匠）
典型任务：企业官网搭建（WordPress/ThinkPHP）、微信小程序开发、简单的 CRUD 后台管理系统。
特点：这是目前市场上需求量最大的部分。客户通常是中小企业主，他们需要数字化工具，但雇不起全职开发团队。
我的点评：这是大多数兼职程序员的主战场。如果你能熟练使用 Vue/React + Node/Java/PHP，你就能在这里活得不错。
层级三：解决方案型（顾问）
典型任务：电商系统定制、SaaS 平台 MVP 开发、复杂的自动化工作流、API 接口对接。
特点：客户不再只是让你“写代码”，而是让你“解决问题”。比如客户想做一个“类似淘宝的商城”，你需要告诉他：你不需要淘宝那么复杂，你需要的是这个 SaaS 模板，加上这个支付接口，成本只要十分之一。
我的点评：这里开始体现“咨询”的价值。你卖的不是代码行数，而是你的行业经验和技术选型能力。
层级四：产品型（合伙人）
典型任务：技术入股、长期维护合约、按项目收益分成。
特点：你不再是一次性买卖，而是成为了客户生意的一部分。
我的点评：这是我现在的状态。我不再按小时计费，而是按价值计费。
